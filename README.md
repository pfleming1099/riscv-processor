# RISC-V Processor Model (Codasip Studio)

This is a cycle accurate, instruction accurate emulator for a RISC-V processor developed in Codasip Studio. 

It is compatible with the RV32I instruction set. 

It features fetch, decode, execute, and writeback stages.

It has basic hazard detection and pipelining.

It is only able to be run in Codasip Studio ver. 9.1+
